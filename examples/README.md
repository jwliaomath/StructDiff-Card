# Bundled example: an assembly-selection audit

- **Mobile:** 2HHB, human deoxyhemoglobin coordinate model, chains A–D.
- **Reference:** 1HHO, human oxyhemoglobin crystallographic asymmetric unit,
  chains A–B.
- **Mode:** US-align `-mm 1 -ter 1`.

The chain counts intentionally differ. US-align maps 2HHB C/D to 1HHO A/B;
2HHB A/B remain unmatched. This makes the static gallery useful for explaining
why assembly selection, aligned length, and unmatched chains must accompany a
high TM-score or low RMSD.

The v0.2 result also localizes four coherent high-residual regions, colors the
aligned structure on a fixed 0–5 Å scale, and exports residual distance in the
PDB B-factor field for direct PyMOL/ChimeraX coloring.

`input/` contains the public RCSB PDB coordinate files. `result/` is generated by
the same Python API used by the CLI and Streamlit app. Regenerate every output,
the GitHub Pages assets, and the 15-second GIF with:

```bash
export USALIGN_BIN=/path/to/USalign
uv run python scripts/regenerate_example.py
```
